# NeuroNexus Task: Google Form-like Web Form (HTML + CSS)

This project is a simple Google Form-like web form built using only **HTML and CSS** — without any JavaScript. It collects user information such as name, contact details, address, and more, and includes a confirmation message after form submission.
Features
 Clean, minimal Google Form-inspired design
- Fields:
  - Full Name (Text)
  - Contact Number (Phone)
  - Address (Multiline Textarea)
  - Company Name (Text)
  - Email Address (Email)
  - Department (Dropdown Menu)
  - Gender (Radio Buttons)
- Submit button with hover effect
- Box-shadow and form background for neat UI
- **Success message** after submission using CSS-only techniques or redirect

- #### Main file is "home.html"
